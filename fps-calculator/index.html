How the estimate works

Each CPU and graphics card has a gaming score from public review averages (graphics: RTX 4070 = 100; CPUs: Ryzen 7 7800X3D = 100). Each game has reference frame rates measured on a known PC. The CPU sets the frame rate a game can reach (memory speed and channels nudge it), the graphics card sets what each resolution allows, short of video memory costs extra, and the slower of the two dominates.

Prices are rough US prices from late 2026, when graphics cards and memory cost far more than usual. Parts no longer sold new show a used price. The same data powers the PC builder inside Pulse, and it's open on GitHub.
